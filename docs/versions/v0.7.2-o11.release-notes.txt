ListUtils O11 0.7.2 - negative indices, two data fixes, 1,388 tests
Released 2026-10-29


OVERVIEW
--------

ListUtils O11 is an OutSystems 11 Integration Studio extension for
server-side list manipulation. It pops, filters, partitions, groups,
joins, compares, slices, samples, updates, aggregates, chunks and flattens
lists of records.

Lists are passed as JSON arrays, so the actions work with any Structure,
Entity record or JSON payload. Serialize a Record List with JSON Serialize,
call ListUtils, then deserialize the returned JSON.


WHAT CHANGED IN 0.7.2
---------------------

Changed - List_Pop and List_PopMultiple now treat negative indices as
  counting from the end (-1 is the last element), like List_SplitAt,
  List_UpdateAt, List_UpdateMultipleAt, List_Slice and [-1] paths.
  Negatives that are still out of range keep the old behaviour. In
  List_PopMultiple, "2,-1" on a 3-item list removes the element once.
  Behaviour change: a negative index used to do nothing.

Fixed - List_UpdateAt, List_UpdateMultipleAt and List_ReplaceWhere no
  longer leave an empty object behind when the path goes through a
  missing array (for example Items[0].Name) or contains an empty segment
  after a missing object. The item is now left unchanged.

Fixed - List_Difference with NotEquals no longer drops every element of
  list A when list B has no key values. All of A is kept.

XIF - regenerated from the O11 project and recompiled with Integration
  Studio Verify and Save. All 814 verifier checks passed, including the
  open, save and recompile round-trips. Parameter descriptions for
  List_Pop.Index and List_PopMultiple.IndicesToPop were updated.


SECURITY PIPELINE POSITION
--------------------------

Not applicable. ListUtils is a general-purpose data manipulation library.
It does not access databases, files, networks or external services.

  List_SplitAt                   Split into left and right lists

  List_PopByConditions           Remove first or last AND/OR match
  List_PopMultipleByConditions   Remove every AND/OR match

Grouping, join and set

  List_GroupByMultiple           Group by composite key

  List_ZipMany                   Pair many lists by position
  List_ZipManyGroupBy            Cogroup many lists by key
  List_ZipManyGroupByMultiple    Cogroup many lists by composite key
  List_Difference                A minus B by key
  List_Intersect                 A and B by key
  List_Union                     A plus B, deduplicated by key

Transformation

Update

PROCESSING MECHANISM
--------------------

Each action parses JSON with System.Text.Json, performs the list operation,
and returns new JSON text. It does not mutate the caller's Record List.

Property paths support nested objects and array indexing, including
negative indices. Condition actions support Equals, NotEquals, Contains,
StartsWith, EndsWith, GreaterThan, LessThan, GreaterOrEqual and
LessOrEqual. Logical operators are AND and OR.


SUPPORTED INPUT
---------------

JSON arrays of objects
  Records serialized from OutSystems Structures or Entities, or JSON from
  integrations.

JSON arrays of scalar values
  Supported by order-based actions such as Pop, Slice, Reverse, Chunk,
  Flatten, Shuffle and Sample.

TextItem Record Lists
  Lists of key paths, key names, field labels and JSON-array strings.

Condition Record Lists
  AND/OR filters and updates.


RECOMMENDED USAGE PATTERN
-------------------------

1. Build or fetch a Record List.
2. Convert it with JSON Serialize.
3. Call the required ListUtils action.
4. Convert returned JSON with JSON Deserialize.
5. Catch exceptions where input JSON comes from users or integrations.

KNOWN LIMITATIONS
-----------------

Invalid JSON - malformed JSON or a non-array root raises a server exception.
Large payloads - each call parses and writes JSON; batch very large data.
Assembly conflicts - another extension may load incompatible
  System.Text.Json dependency versions; use binding redirects if needed.
.NET Framework 4.8 - required by the extension.
Numeric parsing - numeric operators use InvariantCulture.
Random actions - Seed 0 is non-deterministic; use a non-zero seed for
  repeatable output.
