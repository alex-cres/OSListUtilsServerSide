## Added

### Server Actions (7)

- `List_Pop(SourceListJson, Index) → UpdatedListJson, PoppedElementJson` — removes an element at a specific index and returns both the modified list and the removed element.
- `List_PopMultiple(SourceListJson, IndicesToPop, …)` — removes multiple elements at comma-separated indices and returns all removed elements in original order. Reverse-sorted internally to avoid index shifting; out-of-range and duplicate indices ignored.
- `List_PopByCondition(SourceListJson, PropertyName, TargetValue, ComparisonOperator, CaseSensitive, …)` — pops the first element whose property matches the given value.
- `List_PopMultipleByCondition(SourceListJson, PropertyName, TargetValue, ComparisonOperator, CaseSensitive, …)` — pops every element matching the condition.
- `List_Zip(ListAJson, ListBJson, KeyNameA, KeyNameB, …)` — pairs two JSON lists by matching index into objects `{KeyNameA: …, KeyNameB: …}`. Truncates to the shorter list.
- `List_GroupBy(SourceListJson, PropertyName, …)` — groups a flat JSON list by a property value into `{Key, Items}` groups. Preserves insertion order via a parallel key list.
- `List_Difference(ListAJson, ListBJson, MatchKey, ComparisonOperator, CaseSensitive, …)` — set difference A − B on a keyed property.

### Comparison Operators

- Nine operators supported on all condition-based single-condition actions and `List_Difference`: `Equals` (default), `NotEquals`, `Contains`, `StartsWith`, `EndsWith`, `GreaterThan`, `LessThan`, `GreaterOrEqual`, `LessOrEqual`.
- Symbol aliases: `!=`, `>`, `<`, `>=`, `<=`.
- Numeric operators parse both sides as `decimal` with `InvariantCulture`; non-numeric values evaluate as no-match.
- `CaseSensitive` boolean parameter toggles between `StringComparison.Ordinal` and `OrdinalIgnoreCase` for string operators.

### Property Paths

- Dot-separated nested paths on all condition-based actions and `List_GroupBy` (e.g. `Address.City`, `Wrapper.Data.Value`).
- CamelCase fallback per segment — accommodates the `JSON Serialize` behaviour that lowers PascalCase attribute names in nested structures.

### ODC External Library — `ListUtils/` (net10.0)

- `IListUtils` (`[OSInterface]`) — exposes the 7 Server Actions.
- `ListUtils` — implementation.
- All exposed parameters are `Text` / `Integer` / `Boolean` — lists cross the boundary as JSON strings for generic Structure support.
- NuGet dependency: `OutSystems.ExternalLibraries.SDK` 1.5.0.
- `generate_upload_package.ps1` — publishes `linux-x64`, zips to `ExternalLibrary.zip`, enforces the 90 MB ODC Portal limit.
- `resources/icon.png` — 64×64 component icon.

### O11 Integration Studio Extension — `ListUtils.O11/` (net48)

- `IssListUtils` — O11 interface with the 7 `MssList_*` methods.
- `CssListUtils` — implementation. Logic identical to the ODC side, with `ss`-prefixed parameters, `Mss` method prefix, and net48-compatible syntax (`str.Substring(1)`, explicit `new JsonSerializerOptions { … }`, `IndexOf(target, cmp) >= 0` instead of `Contains(target, cmp)`).
- NuGet dependency: `System.Text.Json` 8.0.5 (net48 has no BCL JSON support).
- `resources/icon.ico` — 32×32 ICO for Integration Studio.
